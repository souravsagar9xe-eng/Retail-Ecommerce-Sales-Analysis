# Retail & E-commerce Sales Analysis

## Project Overview
An interactive Retail & E-commerce Sales Performance Dashboard built using Microsoft Excel to analyze sales, profit, orders, products, and customer performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas

## Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold
- Average Order Value (AOV)

## Dashboard Features
- Monthly Sales Trends
- Category Performance
- Top 5 Products
- Sales Channel Analysis
- Payment Mode Analysis
- Order Status Analysis
- Year & Quarterly Sales Analysis
- Region-wise Filtering

## Project Files
- Excel Dashboard Workbook (.xlsx)
- Dashboard Preview (.png)

## Objective
To transform raw retail sales data into meaningful business insights through interactive Excel reporting.
